# ENG-3788 — crew wiki cell posture

Status: pending human ratification
Owner: Orvex Wiki product-platform owner
Decision: CLOUD=false for both crew cells
Recorded: 2026-09-08

## Rationale

Crew is a per-developer parallel stack, not a promoted multi-tenant cloud cell.
Its `CELL_ID=solo` sentinel is therefore intentional, while the crew component
already isolates each stack's event spine with `EVENT_TOPIC_SUFFIX=crew-{name}`.
Setting `CLOUD=false` matches that runtime meaning and avoids minting synthetic
per-cell identities or implying that crew workspaces belong in the cell registry.

This posture also prevents the ENG-3789 boot assertion from rejecting crew:
the assertion applies only to `CLOUD=true` with an unset or `solo` `CELL_ID`.
The source implementation is present in
`deploy/kustomize/components/crew/kustomization.yaml`; CI remains fail-closed
until this record is ratified by the named owner.
